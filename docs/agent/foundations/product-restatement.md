# Product Restatement

## What this product is

This product is a persistent virtual-world operating system for AI agents, managed through a web interface and designed for long-running narrative simulation.

It is not a generic chatbot app and not a multi-agent office workflow tool.

## Core entities

- **Platform admin**: manages platform-level defaults and access.
- **World admin**: creates and configures worlds, agents, rules, providers, and permissions.
- **Human user**: may participate inside a world as a managed human actor.
- **Agent runtime**: non-human runtime identity for autonomous role agents.

## Core system roles

- **Role agents**: long-running actors with private persona, private memory, private calendar, and isolated runtime context.
- **Narrative agent**: privileged summarizer/writer that turns authorized world events and summaries into readable story artifacts.
- **World clock and event broadcaster**: authoritative source of time progression and schedule/event broadcasts.

## Core user value

- Run a living world continuously.
- Observe it through a dashboard.
- Keep agent state isolated and rule-constrained.
- Turn events into readable story output.

## Product form

- Web-only control surface
- Linux self-hosted deployment
- Multiple worlds inside one program
- Strong world-scoped isolation

## Product philosophy

- World logic lives in code and configuration, not in free-form prompts.
- Agents receive filtered observations, not unrestricted world state.
- Narrative output is a derived artifact, not the source of truth.
