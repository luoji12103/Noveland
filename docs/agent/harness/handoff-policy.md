# Handoff Policy

Every session must leave a clean handoff.

## Required sections

- date/time
- branch
- objective worked on
- completed work
- incomplete work
- exact files changed
- tests run
- current risks
- recommended next step
- sensitive areas to avoid casual edits

## Archival rule

- `handoffs/active-session.md` is the only live handoff file
- previous handoffs may be moved to `handoffs/archive/`
