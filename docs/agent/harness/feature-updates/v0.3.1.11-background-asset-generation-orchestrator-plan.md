# v0.3.1.11 Background Asset Generation Orchestrator Phase 11 Plan

Phase 11 adds an admin-reviewed asset generation orchestrator. It analyzes a worldline and conversation for missing visual/speech assets, records proposals, and lets an admin explicitly apply selected proposals into queued `media_jobs`.

## Scope

- Backend/API only.
- Proposal plus admin apply only.
- No daemon hook, automatic provider execution loop, Web UI, realtime pre-generation, streaming, or automatic spend.
- Preview/apply must not call provider adapters.
- Reuse existing `media_jobs` priority, cancel policy, deadline, invalidation key, and request JSON fields.

## Proposal Rules

Preview analyzes:

- `conversation_turn_presentations`
- `character_sprite_sets` / `character_sprite_variants`
- `scene_background_profiles`
- `voice_profiles` / `agent_voice_profile_bindings`
- provider capabilities from `ProviderRegistryService`

Priority:

- P0: current visible turn missing required visual/speech asset
- P1: active conversation support
- P2: near-future lookahead
- P3: offscreen/background

Preview persists proposals but creates no media jobs and calls no providers.

Apply:

- Applies selected proposal IDs or all currently proposed proposals from a preview run.
- Creates queued media jobs with safe `request_json`, `priority`, `cancel_policy`, `deadline_hint`, and `invalidation_key`.
- Marks applied proposals and links `resulting_media_job_id`.
- Leaves unselected proposals as `proposed`.
- Does not execute provider adapters.

## Guardrails

- Do not write to `world_events.payload`.
- Do not include storage URI, file path, base64, bytes, raw prompt, or raw output in proposal or job payloads.
- Reject cross-worldline targets.
- Cost budgets block excess proposals deterministically.
- Missing provider capability blocks proposals with an explicit reason.
- Cancel-superseded must not cancel succeeded, failed, or already-cancelled jobs.
