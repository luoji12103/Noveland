# v1.1.4 Content Safety & Moderation Hardening Plan

Date: 2026-05-21
Branch: `feature/v1.1-4-content-safety-moderation-hardening`
OpenSpec change: `v1-1-normal-use-release-candidate`

## Decision

Phase 4 will harden the existing moderation package as the safety/action owner and keep beta feedback as contextual tester feedback. It will not create a duplicate moderation framework, public forum, Web UI, migrations, broad `worlds.py` routes, or automatic punitive actions.

## Ownership

- Safety/action owner: `backend/packages/moderation/`
- Beta feedback escalation source: `backend/packages/beta_feedback/`
- Reader/player suppression: existing reader delivery checks through moderation applied actions
- Player data export/delete ownership: `backend/packages/player_privacy/`

## Implementation Scope

- Add a moderation safety-review helper that creates safe moderation reports from player-visible output findings.
- Add explicit beta-feedback-to-moderation escalation that links the feedback report to a moderation report and preserves reporter privacy.
- Keep moderation report listing/admin evidence admin-only.
- Keep tester feedback lists reporter-private.
- Preserve applied takedown/media/world suppression through existing moderation actions.
- Return only safe evidence refs and sanitized metadata.

## Non-goals

- Public moderator UI.
- Web UI changes.
- Automatic disable/takedown from feedback alone.
- Provider calls or model-based safety classification.
- Player privacy export/delete ownership changes.

## Tests

- Unsafe player-visible output can be flagged into a safe moderation report.
- Safety beta feedback can escalate to moderation with safe refs and privacy boundaries.
- Other testers cannot see reporter-private feedback or admin moderation evidence.
- Applied takedown continues to hide reader-visible media.
- No raw prompt/output, storage path, provider secret, or reporter-private leak.

## Stop Conditions

- Escalation would expose reporter private data to other testers.
- Safety evidence requires raw prompts, prompt snapshots, storage paths, bytes, or secrets.
- Moderation hardening becomes a public social/forum feature.
- Takedown would mutate world state without auditable moderation action evidence.
