# v0.7.1 Permission Matrix & ACL Regression Baseline Plan

## Goal

Establish a concrete permission matrix and focused ACL regression baseline for the current v0.4-v0.6 route surface before deeper production hardening begins.

This phase is API/test/docs-first. It should only fix enforcement gaps discovered by the matrix and focused tests.

## Scope

- Document the current route permission matrix for:
  - unauthenticated
  - platform admin
  - world admin
  - world member
  - reader/player-facing projections
- Cover v0.4-v0.6 high-risk admin surfaces:
  - providers
  - model invocations and prompt snapshots
  - media admin assets/objects/jobs
  - authoring/import proposals
  - multimodal evals
  - narrative quality diagnostics
  - visual/speech admin records
  - conversation turn presentations
- Add lower-privilege regression tests for forbidden access and leak suppression.
- Preserve existing `auth` package and API authorization dependency boundaries.
- Keep any implementation fixes narrowly scoped to ACL enforcement.

## Non-goals

- No new public launch routes.
- No Web UI.
- No new role hierarchy UI.
- No large auth schema redesign.
- No broad `worlds.py` refactor.
- No production readiness gate implementation.
- No provider, media, narrative, or authoring feature expansion.

## Reused Systems

- `noveland.auth`
- `world_memberships`
- `require_platform_admin`
- `require_world_admin`
- `require_world_member`
- `get_world_admin_context`
- `get_world_member_context`
- Existing API router tests and helper fixtures

## Deliverables

- Route permission matrix document.
- Focused ACL/leak regression tests.
- Any required narrowly scoped ACL fixes.
- Updated OpenSpec Phase 1 task status and harness docs after implementation.

## Guardrails

- Member/reader/player routes must not expose prompt snapshots, raw prompts, raw outputs, resolved provider secrets, storage paths, bytes, base64, hidden/developer-only media, or admin-only diagnostic evidence.
- Admin diagnostics may expose safe evidence refs and aggregate counts only.
- Do not write forbidden data into `world_events.payload`.
- Do not add broad routes to `worlds.py`.

## Stop Conditions

- Existing platform role/world membership schema cannot express the accepted matrix.
- Fixing an ACL gap requires broad `worlds.py` rewrites.
- A lower-privilege projection would need raw prompts, raw outputs, prompt snapshots, resolved secrets, storage paths, bytes, or base64.
- Targeted tests or the full local gate fail.

## Targeted Tests

- Permission matrix file exists and covers the high-risk routers.
- World member cannot access provider, authoring, narrative quality, invocation, media admin, visual admin, speech admin, presentation, or multimodal eval admin routes.
- Unauthenticated requests are rejected.
- Lower-privilege API responses do not leak storage URI, filesystem path, raw prompt/output, prompt snapshot data, resolved secrets, bytes, or base64.
- Existing admin access paths still work.

## Validation

- Targeted ACL regression tests.
- `openspec validate --changes --strict`
- `openspec validate --specs --strict`
- Full local gate before fast-forward merge.
