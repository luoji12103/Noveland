# v1.1.5 Import/Export Stability Plan

Date: 2026-05-21
Branch: `feature/v1.1-5-import-export-stability`
OpenSpec change: `v1-1-normal-use-release-candidate`

## Decision

Phase 5 will extend the existing `world_packaging` manifest/preview/apply boundary. It will not create a new import/export framework, migration, Web UI, marketplace path, broad `worlds.py` routes, or direct source-content importer.

## Ownership

- Manifest, export preview, import preview, and import apply: `backend/packages/world_packaging/`
- Existing API route: `backend/services/api/src/noveland/services/api/world_packaging.py`
- Provider config safety remains aligned with `package_contracts` and provider secret governance.
- Source content import remains owned by `authoring`; package import must not bypass preview/review/apply for source-derived content.

## Implementation Scope

- Add safe manifest sections for provider config, persona, memory, visual mappings, voice mappings, and source traceability.
- Export these sections from existing world-scoped records using portable keys and sanitized metadata only.
- Exclude or placeholder proprietary/user-provided galgame source assets from public sample/export manifests.
- Add repeatable import-preview duplicate/compatibility warnings for existing package keys or repeated sample package imports.
- Keep apply explicit and non-provider-executing. Specialized persona/memory/visual/voice records are preserved as safe import metadata until existing review/apply paths consume them.

## Non-goals

- Resolved secret export.
- Raw prompt snapshot export.
- Storage path, object path, bytes, or base64 export.
- Proprietary/user-provided galgame asset fixture export.
- DRM bypass, unpacking, cracking, or decryption.
- Web import/export UI changes.

## Tests

- Export includes safe provider/persona/memory/visual/voice/source manifests without secrets or storage paths.
- Public/sample export excludes user-provided galgame assets with safe exclusion warnings.
- Import preview reports duplicate package compatibility safely.
- Import apply remains explicit, creates placeholder-safe records, and preserves extended manifests as safe metadata.
- Sample package import remains deterministic and repeatable.

## Stop Conditions

- Export requires resolved secrets or local storage paths.
- Import bypasses preview/review/apply for source-derived content.
- Proprietary/user-provided assets would enter repository fixtures.
- Package import mutates provider, persona, memory, visual, or voice state directly outside existing apply owners.
