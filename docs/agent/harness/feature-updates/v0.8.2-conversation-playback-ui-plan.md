# v0.8.2 Conversation Playback UI Plan

Date: 2026-05-15
Branch: `main`

## Scope

Implement the first reader/player conversation playback surface after Phase 1 Reader Media Delivery. This phase is Web-focused and must consume only reader-safe media descriptors plus existing conversation turn and presentation DTOs.

## Accepted Design

- Add a reader/player-facing playback route under the existing reader surface.
- Reuse the existing `WorkspaceShell`, reader page conventions, and same-origin world proxy.
- Use existing conversation sessions, conversation turns, and turn presentation endpoints.
- Use Phase 1 reader media descriptors for image/audio delivery references.
- Render dialogue text/subtitles, turn emotion, render state, and safe media presence.
- Display image media through application-mediated reader media download URLs only.
- Play audio only through reader media download URLs.
- Preserve loading, empty, unauthorized, and missing-media states.

## Non-Goals

- No backend migration.
- No new provider execution.
- No editing or authoring controls.
- No public unauthenticated access.
- No direct admin media DTO usage.
- No raw prompt/output, prompt snapshot, storage URI, filesystem path, base64, bytes, or resolved secret exposure.
- No broad route growth in `worlds.py`.

## Implementation Notes

- Web types should model reader media descriptors separately from admin media DTOs.
- Server data loading may fetch conversation, turns, optional presentations, and reader media descriptors through existing authenticated API boundaries.
- The UI should map media descriptors by referenced conversation turn/session and referenced asset IDs from presentation records.
- Missing presentation or media should be shown as deterministic safe fallback, not as an error stack or random asset.
- E2E fixtures should add only safe descriptor payloads and application-mediated media URLs.

## Targeted Validation

- Web component/unit tests for playback rendering, safe media URLs, fallback states, and no forbidden markers.
- Web client/server mapping tests for reader media descriptor fetches if helper functions are added.
- E2E smoke proving authenticated playback renders turns and unauthenticated users are redirected.
- Full local gate after implementation.
