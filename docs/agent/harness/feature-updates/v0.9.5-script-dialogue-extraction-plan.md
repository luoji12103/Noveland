# v0.9.5 Script Dialogue Extraction Plan

Date: 2026-05-17
Branch: `feat/v0.9-script-dialogue-extraction`

## Goal

Implement v0.9 Phase 5 only: extract dialogue, speaker, scene, choice, route, emotion, relationship, event, and manual-label candidates from imported script fragments as reviewable authoring proposals.

## Scope Decision

Phase 5 is backend/API/docs/tests only.

- Reuse `backend/packages/authoring/src/noveland/authoring/parser.py`.
- Reuse existing authoring import runs, proposal creation, source traceability, and review/apply boundaries.
- Keep provider-backed extraction out of this phase. No model calls, prompt snapshots, invocation ledger writes, or provider spend are needed for deterministic parsing.
- Add no new parser store and no migration.
- Add no Web UI; `impeccable` is not needed.

## Parser Additions

The deterministic parser now keeps the existing selected sample formats and adds:

- `line_text` on dialogue candidates
- emotion hint proposals from `[emotion: ...]` and `@emotion ...`
- relationship hint proposals from `[relationship: ...]` and `@relationship ...`
- manual-label proposals for unrecognized non-comment script lines

Unknown formats remain preserved as source fragments and become reviewable manual-label proposals rather than being silently discarded.

## Safety Rules

- Proposals only; no direct canon, memory, visual, voice, world-state, or world-event mutation.
- Parser evidence stores safe line numbers, source fragment IDs, line excerpts, and parser mode only.
- No raw full-script runtime prompt/context.
- No provider calls by default.
- Existing authoring JSON leak checks continue to reject storage URIs, filesystem-path markers, base64, raw prompts, and raw outputs.

## Stop Conditions

Stop if:

- script extraction requires provider calls to satisfy the current phase;
- unknown formats cannot be preserved as reviewable proposals;
- parser output needs direct writes to canon, memory, visual, voice, or world state;
- proposal payloads would need unsafe raw source blobs or storage/path references;
- a migration becomes required without a separate checkpoint.
