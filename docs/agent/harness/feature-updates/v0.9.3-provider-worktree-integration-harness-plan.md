# v0.9.3 Provider Worktree Integration Test Harness Plan

Date: 2026-05-17
Branch: `feat/v0.9-provider-worktree-harness`

## Goal

Implement v0.9 Phase 3 only: establish a safe provider-lab test discipline for real-provider development without making external calls in the default local gate.

## Scope Decision

Phase 3 is docs/test/backend-only.

- Add provider lab operating docs for a separate worktree such as `../Noveland-provider-lab`.
- Add a strict pytest marker for real provider tests.
- Add default-skip real-provider smoke examples guarded by `NOVELAND_RUN_REAL_PROVIDER_TESTS=1`.
- Add fake/mocked contract coverage for OpenAI-compatible LLM, Anthropic-compatible LLM, MiMo TTS/ASR, Z-Image, GPT Image, ComfyUI, OpenAI-compatible image, and generic/custom HTTP.
- Do not add migrations, backend API routes, Web UI, runtime behavior, or real external calls in the default gate.

## Test Ownership

Default tests remain fake or mocked:

- Provider templates prove required presets exist and are capability-compatible.
- Model discovery uses configured `available_models` or mocked HTTP, never real endpoints by default.
- Provider execution tests use dry-run adapters or fake providers.
- Visual generation mapping tests validate ComfyUI/Z-Image/GPT/OpenAI-compatible/generic mapping without provider execution.

Opt-in real tests use:

```sh
NOVELAND_RUN_REAL_PROVIDER_TESTS=1
```

Real-provider tests must also require provider-specific env such as `NOVELAND_PROVIDER_LAB_OPENAI_BASE_URL`, `NOVELAND_PROVIDER_LAB_OPENAI_MODEL`, and matching `*_AUTH_REF` values. Missing provider-specific settings must skip, not fail.

## Safety Rules

- No committed secrets.
- No hardcoded vendor base URL or API key.
- No default quota spend.
- No raw prompt, raw output, storage URI, filesystem path, bytes, base64, or resolved secret in provider lab evidence.
- Real provider evidence may include provider family, adapter kind, model name, capability, status, and safe error class only.
- Provider execution must use `ProviderExecutionService` and `auth_ref` resolution, not legacy provider profile services.
- Real-provider runs should happen in a separate worktree and should not be treated as CI/default-gate requirements.

## Validation

Phase 3 targeted validation:

```sh
cd backend && uv run pytest tests/test_provider_lab_harness.py
```

Full local gate:

```sh
cd backend && uv run ruff check .
cd backend && uv run mypy .
cd backend && uv run pytest
openspec validate --changes --strict
openspec validate --specs --strict
git diff --check
```

Web validation is not required for Phase 3 because no Web files are touched.

## Stop Conditions

Stop if:

- any test would call a real provider without `NOVELAND_RUN_REAL_PROVIDER_TESTS=1`;
- real-provider setup needs committed secrets or forced base URLs;
- provider lab evidence cannot be redacted to safe status fields;
- test harness requires runtime/API behavior changes beyond docs and tests;
- Web UI becomes required.
