# v0.9.8 Voice Profile Mapping Plan

Date: 2026-05-17
Branch: `feat/v0.9-voice-profile-mapping`
Scope: v0.9 Self-use MVP Demo World Cut Phase 8 only.

## Decision

Phase 8 stays backend/API/docs/tests only. No Web UI is added, so `impeccable` is not required. No migration is required because `VoiceProfile`, `AgentVoiceProfileBinding`, `SpeechStyleMapping`, speech transcripts, media assets, and provider templates already cover the first implementation.

Reviewed `voice_asset_match` proposals will apply through `AuthoringService.apply` only. Apply creates or reuses speech voice profiles, binds them to agents, preserves source/media traceability, and records safe metadata on the reference audio. TTS/STT provider usage continues through the existing speech service and `ProviderExecutionService`.

## Boundaries

- No voice cloning training pipeline.
- No automatic voice migration or cross-language transformation.
- No direct provider calls during authoring apply.
- No hardcoded MiMo endpoint; Phase 1 provider templates keep custom `base_url`/`model_name`.
- No raw reference audio exposure outside authorized media paths.
- No storage URI, local path, bytes, base64, raw prompt, raw output, prompt snapshot internals, or resolved secret exposure.
- No `world_events.payload` writes.

## Implementation Shape

- Reuse Phase 4/5 `voice_asset_match` proposals.
- Resolve the target agent by explicit `agent_id`, then normalized `speaker_label`/`character_label`/`voice_label`.
- Create or reuse one imported voice profile per agent/worldline/profile key.
- Bind the voice profile as the agent default only when no default exists.
- Preserve optional provider/provider voice id metadata without resolving secrets.
- Preserve emotion/style hints as binding overrides.
- Mark approved audio media as voice-reference candidates for later speech workflows.

## Tests

Targeted tests cover:

- Reviewed voice proposal apply to `VoiceProfile` and `AgentVoiceProfileBinding`.
- Worldline isolation and audio-only validation.
- Existing MiMo/generic provider template custom-base-url behavior.
- Fake TTS smoke through the existing speech service with applied binding.
- No secret, storage path, raw prompt/output, base64, or world-event pollution.

## Stop Conditions

- Stop if voice mapping requires a voice cloning or training pipeline.
- Stop if provider voice IDs need secret resolution in authoring apply.
- Stop if speech provider execution cannot remain fake/dry-run by default.
- Stop if Phase 8 unexpectedly needs Web UI and `impeccable` cannot be used first.
