# v0.5.2 Script Parser & Dialogue Extractor Plan

## Goal

Parse script source fragments into reviewable dialogue, scene, choice, route, and event proposals using the Phase 1 authoring import foundation.

## Scope

- Add deterministic parser contracts and service logic inside `backend/packages/authoring/`.
- Add authoring API route(s) under `backend/services/api/src/noveland/services/api/authoring.py`.
- Parse existing `authoring_source_fragments.excerpt_text`; do not accept or persist full raw script bodies in Phase 2.
- Create Phase 1 `authoring_import_proposals` linked to the source fragments and import run.
- Represent speaker resolution status, scene hints, choice labels, route labels, and event keys in safe proposal JSON.
- Keep all generated records worldline-scoped and traceable to source fragments.

## Non-goals

- No migration unless implementation proves the Phase 1 schema cannot carry the parser output.
- No Web UI.
- No provider-backed parsing in Phase 2.
- No invocation ledger changes because no provider parsing is used.
- No direct apply to conversations, scenes, memories, world bible, or narrative state.
- No raw full source text in API responses, prompt snapshots, or `world_events.payload`.
- No changes to `worlds.py`.

## API Shape

- `POST /worlds/{world_id}/authoring/import-runs/{run_id}/parse-script`

Request:

- `worldline_id`
- `source_fragment_ids`
- `parser_mode`: `deterministic`

Result:

- `run`
- `created_proposal_count`
- `dialogue_count`
- `scene_count`
- `choice_count`
- `route_count`
- `event_count`
- `unresolved_speaker_count`

## Parser Rules

- Dialogue:
  - `Speaker: text`
  - `Speaker: "text"`
  - `Speaker「text」`
- Scene candidates:
  - `[scene: key]`
  - `# scene key`
  - `@scene key`
- Choice candidates:
  - `choice: label`
  - `-> label`
- Route candidates:
  - `[route: key]`
  - `@route key`
- Event candidates:
  - `[event: key]`
  - `@event key`
- Quoted dialogue without an explicit speaker creates a dialogue proposal with unresolved speaker metadata.
- Unknown lines are skipped rather than guessed.

## Guardrails

- Generated proposals must reuse Phase 1 safe JSON validation.
- Parser output must not include `storage_uri`, filesystem paths, raw bytes, base64, raw prompts, raw outputs, or full raw source.
- Parser must not create provider invocations, media jobs, memory writes, world events, conversation turns, scenes, agents, or world bible records.
- Cross-world and cross-worldline source fragments must be rejected.
