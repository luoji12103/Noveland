# v0.4 Operator/Admin UX Release Notes

## Summary

v0.4 completes the operator/admin Web layer for the Phase 3-13 multimodal backend foundation. It adds world-scoped admin pages for provider integrations, media assets, visual assets, speech assets, invocation ledger inspection, and multimodal diagnostics, plus shared admin UX primitives used across those pages.

## Released Scope

- Admin UX foundation: shared admin notices, summaries, metrics, tables, detail panels, action states, and route guard/client conventions.
- Provider admin console: world-scoped provider integration list/detail, capability view, health history, smoke-test action, and safe `auth_ref` status display.
- Media admin console: media asset/object/job/reference inspection, upload, safe download, status/visibility filters, and lineage review.
- Visual admin console: strict-worldline sprite sets, sprite variants, scene backgrounds, resolver previews, and compose-scene preview through existing visual/image APIs.
- Speech admin console: voice profiles, agent voice bindings, style mappings, transcripts, and explicit TTS/STT test actions through existing speech APIs.
- Invocation ledger browser: invocation search/detail, prompt snapshot evidence, tag actions, redaction action, visibility, and retention display.
- Multimodal diagnostics dashboard: current diagnostic findings, safe evidence refs, component summaries, recent eval runs, and explicit multimodal smoke eval action.

## Guardrails Preserved

- No backend behavior changes, migrations, provider adapters, storage backends, or runtime daemon behavior were added by v0.4.
- No `worlds.py` refactor was introduced.
- No resolved provider secrets are displayed.
- No `storage_uri`, filesystem path, bytes, base64 payload, raw prompt, or raw output is intentionally exposed through v0.4 admin UI responses.
- No public reader media delivery, streaming, provider marketplace, or Web preview/playback editor was added.
- All new Web surfaces call existing backend APIs and preserve backend ACL, world, and worldline validation.
