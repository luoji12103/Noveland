# v0.8 Public Experience & Ecosystem Release Notes

## Summary

v0.8 completes the first authenticated public-experience foundation. It adds reader-safe media delivery, reader/player playback surfaces, player interaction and privacy controls, safe world packaging, plugin/provider package contracts, a deterministic sample release package, moderation and incident workflow records, and a public launch readiness gate.

## Released Scope

- Reader Media Delivery: authenticated reader/member/player/admin descriptors and app-mediated downloads with visibility-policy intersection.
- Conversation Playback UI: reader/player playback over safe presentation DTOs, subtitles, scene media, and optional audio.
- Player Interaction UI: choices, interventions, journal entries, notifications, and safe route/relationship feedback using existing player records.
- Worldline Browser: read-only worldline list/detail and safe comparison summaries without rollback, merge, or branch mutation.
- Scene View / Galgame View: basic scene surface with background, sprites/composite media, dialogue, audio, and deterministic fallback states.
- Player Privacy & Data Controls: sanitized export records, reviewable delete/redaction requests, and shared-world safeguards.
- World Packaging: safe world/media manifests, export preview, import preview, and explicit apply discipline.
- Plugin/Provider Package Contract: metadata/capability validation and safe provider config export without marketplace or secret exposure.
- Sample World Release Package: deterministic sample package helper based on the Phase 13 fixture, with rights/visibility metadata and packaging checks.
- Moderation & Incident Workflow: report, review, takedown/disable, incident, and audit records through a dedicated moderation boundary.
- Public Launch Gate: platform-admin readiness report that reuses v0.7 production readiness and adds v0.8 public-surface evidence and explicit signoff flags.

## Guardrails Preserved

- Reader media delivery remains authenticated-only; no public unauthenticated media delivery was added.
- Reader/player APIs and Web surfaces do not expose `storage_uri`, filesystem paths, object storage paths, bytes, base64, raw prompts, raw outputs, prompt snapshot internals, or resolved secrets.
- `world_events.payload` remains free of storage paths, bytes/base64, raw prompt/output, and resolved secrets.
- Public launch readiness does not auto-launch or auto-publicize worlds.
- Provider marketplace, automatic provider spend, daemon execution, streaming, and public CDN delivery remain deferred.
- v0.8 did not duplicate the media, provider, readiness, release, or eval frameworks.
- Broad new routes were not added to `worlds.py`.

## Deferred Items

- Public unauthenticated media delivery and CDN integration.
- Marketplace distribution and user-managed provider package installation.
- Streaming media, streaming playback, and full game-engine style rendering.
- Automatic moderation actions without review.
- Automatic public launch or release publication.
- New v0.9 planning and implementation.
