# v0.5 Authoring & Import Studio Release Notes

## Summary

v0.5 completes the backend-only Authoring & Import Studio foundation. It adds a dedicated `backend/packages/authoring/` package and world-scoped `authoring.py` router for source registry, import runs, proposals, review decisions, source traceability, deterministic extractors, proposal-only memory/asset migration, and an authoring regression fixture.

## Released Scope

- Authoring import core: strict-worldline source batches, source assets, source fragments, import runs, proposals, review decisions, source traceability, preview, and guarded trace-only apply.
- Script parser and dialogue extractor: deterministic proposal creation for dialogue, unresolved quoted dialogue, scenes, choices, routes, and event markers.
- Character and relationship extractor: deterministic proposals for characters, aliases, factions, identities, relationships, and emotional baselines.
- World bible and lore extractor: proposal-only lore, location, organization, world-rule, secret, knowledge-boundary, and uncertain-canon candidates.
- Canon conflict review: deterministic duplicate, contradiction, uncertain, and OOC-risk conflict report proposals.
- Memory migration pipeline: proposal-only fact, episodic, relationship, preference, and style memory candidates without memory writes.
- Asset import and matching: proposal-only sprite, background, CG, and voice-reference asset match candidates without media jobs or binding writes.
- Authoring regression fixture: deterministic sample import coverage for v0.5 pipeline, guarded apply, side-effect checks, and leak checks.

## Guardrails Preserved

- Authoring/import logic lives under the dedicated authoring package/router; broad v0.5 logic was not added to `worlds.py`.
- All v0.5 authoring records are strict-worldline and world-scoped.
- No provider execution, provider adapters, runtime daemon work, Web UI, public reader delivery, or streaming was added.
- Preview/extract/migrate/match/apply flows do not append `world_events`.
- Asset matching does not create media jobs, visual bindings, speech bindings, or provider invocations.
- Memory migration does not enqueue `MemoryWriteJob` records.
- Lore/world-bible extraction remains proposal-only and does not mutate global canon.
- Authoring JSON validation rejects storage URIs, filesystem paths, bytes, base64, raw prompts, raw outputs, and raw source keys/values.
