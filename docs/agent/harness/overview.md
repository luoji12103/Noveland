# Harness Overview

The harness exists to preserve continuity across sessions, contributors, and coding agents.

## Goals

- stable context recovery
- change traceability
- debug traceability
- structural awareness
- controlled file growth
- explicit handoff discipline

## Core working files

- `project-index.md`
- `file-inventory.md`
- `ownership-map.md`
- `task-board.md`
- `change-journal.md`
- `debug-journal.md`
- `handoffs/active-session.md`

## Session rule

A session is not complete until the working files reflect the real state of the codebase.
