## Why

Noveland needs player identity, structured choices, consequences, branch saves, and branch isolation before route systems or beta-quality player experience can be reliable.

## What Changes

- Add requirements for player actor profiles, choice records, consequence preview/application, branchable worldlines, snapshot forks, memory isolation, and branch comparison.
- Preserve existing worldline-first multimodal state and event/snapshot architecture.
- Avoid public launch, Web-heavy route UX, and automatic memory/provider bypasses in the initial proposal.

## Capabilities

### New Capabilities
- `player-choice-worldlines`: Player actor, choice consequence, branchable worldline, branch memory isolation, and timeline comparison requirements.

### Modified Capabilities
- None.

## Impact

- Future worldline, event, memory, conversation, narrative, and Web extensions.
- Future migration work for player actor and choice records.
- No current implementation change in this planning commit.
