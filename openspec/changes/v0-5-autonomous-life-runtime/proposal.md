## Why

After core world model foundations exist, Noveland needs controlled autonomous life behavior so characters and organizations can create daily/offscreen activity without turning provider execution or background generation into hidden spend.

## What Changes

- Add requirements for character presence, daily scheduling, offscreen event queue, event importance, GM agenda, GM proposals, and deterministic event resolution.
- Keep provider execution explicit and audited.
- Keep asset generation proposal/admin apply boundaries intact.

## Capabilities

### New Capabilities
- `autonomous-life-runtime`: Controlled world runtime behavior for character presence, daily life, offscreen events, GM planning, and deterministic event proposal/resolution.

### Modified Capabilities
- None.

## Impact

- Future runtime, world, calendar, event, memory, and diagnostics extensions.
- Future tests for replay compatibility, loop controls, ACL, and provider/invocation boundaries.
- No current implementation change in this planning commit.
